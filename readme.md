# Functional TypeScript Agent Skill

A guide for large language models to write good functional TypeScript.

This repository is compatible with the Agent Skills format used by Vercel's `npx skills` CLI and other skills-compatible coding agents.

## Install

```sh
npx skills add nikudaorg/typescript-guide
```

To install from a local checkout during development:

```sh
npx skills add .
```

## Contents

- `SKILL.md` - Agent Skills-compatible metadata and instructions.
- `guide.md` - Original plain Markdown guide.
